## ⚡ 步骤1: 硬件连接 (2分钟)

### 简化接线图

```
ESP32开发板
┌─────────────┐
│  GPIO引脚    │
└──────┬──────┘
       │
  ┌────┼────────┬────────┐
  │    │        │        │
  ▼    ▼        ▼        ▼
HTU21D ZE08   S8      电源
(I2C) (UART2) (UART1)  
```

### 详细接线表

| ESP32引脚 | 连接到 | 说明 |
|----------|--------|------|
| **3.3V** | HTU21D VCC | 橙色线 |
| **GND** | HTU21D GND | 黑色线 |
| **GPIO21** | HTU21D SDA | 绿色线 + 4.7kΩ上拉到3.3V |
| **GPIO22** | HTU21D SCL | 黄色线 + 4.7kΩ上拉到3.3V |
| **5V** | ZE08 Vin | 红色线 |
| **GND** | ZE08 G0 | 黑色线 |
| **GPIO16** | ZE08 TX | 绿色线 |
| **GPIO17** | ZE08 RX | 黄色线 |
| **5V** | S8 G+ | 红色线 + 并联1000μF电容 |
| **GND** | S8 G0 | 黑色线 |
| **GPIO4** | S8 TX | 绿色线 |
| **GPIO5** | S8 RX | 黄色线 |

⚠️ **重要提醒:**
- ZE08和S8**必须**接5V,不能接3.3V!
- S8电源端**必须**并联1000μF电容!
- 所有GND必须连接在一起!

## 💻 步骤2: 编译固件 (2分钟)

### 一键编译烧录

```bash
# 1. 克隆或下载代码
cd /data/info/esp/esp32_firmware

# 2. 修改WiFi配置(编辑main.ino)
# const char* WIFI_SSID = "你的WiFi名称";
# const char* WIFI_PASSWORD = "你的WiFi密码";

# 3. 连接ESP32到电脑USB

# 4. 编译并烧录
pio run --target upload

# 等待显示SUCCESS
```

### 预期输出

