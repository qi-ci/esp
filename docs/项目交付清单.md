## 🛠️ 硬件配置确认

### 电压要求(重要!)

| 传感器 | 工作电压 | 连接方式 | 警告 |
|--------|---------|---------|------|
| HTU21D | 1.5-3.6V | ESP32 3.3V | ⚠️接5V会烧毁! |
| ZE08-CH2O | 3.7-5.5V | ESP32 5V | ❌不能用3.3V |
| S8 0053 | 4.5-5.25V | ESP32 5V + 1000μF电容 | ❌不能用3.3V |

### 引脚分配

| ESP32 GPIO | 功能 | 传感器信号 |
|-----------|------|-----------|
| GPIO21 | I2C SDA | HTU21D SDA |
| GPIO22 | I2C SCL | HTU21D SCL |
| GPIO16 | UART2 RX | ZE08 TX |
| GPIO17 | UART2 TX | ZE08 RX |
| GPIO4 | UART1 RX | S8 TX |
| GPIO5 | UART1 TX | S8 RX |

✅ 所有引脚已在代码中正确配置

## 📞 技术支持

### 常见问题FAQ

**Q: 在哪里可以找到电路图?**  
A: 参考产品需求说明书第2.7节,有完整的ASCII电路图和接线表。

**Q: 如何修改WiFi配置?**  
A: 编辑 `esp32_firmware/main.ino`,修改WIFI_SSID和WIFI_PASSWORD。

**Q: 为什么选择方案B而不是A?**  
A: 用户明确要求节能模式,方案B续航11天 vs 方案A的7天,更适合长期使用。

**Q: 传感器寿命管理有用吗?**  
A: 非常有用!ZE08电化学元件会衰减,S8需要定期校准,这些都能延长使用寿命并保持准确性。
